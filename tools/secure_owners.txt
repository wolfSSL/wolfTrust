# Owner of every object linked into the Secure image.
#
# tools/check_secure_layout.py reads the linker map and fails the link unless
# every writable input section lies in its owner's region: a partition's data
# band, or SPM-private RAM for "spm". A "shared" object runs in more than one
# domain and may hold no writable state at all. An object with no entry fails
# the link, so a new source file cannot land without an owner.
#
# A trailing "*" names a generated family (the Arm conformance sources).
#
